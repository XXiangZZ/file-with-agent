# 交付说明

> 注意：应直接交付 `archive_with_all` 目录内的内容，而不是再套一层 `archive_with_all` 文件夹。

正确结构示例：

```text
archive_with_all.exe
_internal/
data/
```

错误结构示例：

```text
archive_with_all/ archive_with_all.exe
archive_with_all/ _internal/
```


## 运行环境要求

为避免 Paddle 模型加载失败，请客户解压到一个纯 ASCII 路径，例如：

- `C:\archive_with_all`
- `D:\OCRApp`

不要解压到包含中文、空格或特殊字符的路径，例如：

- `F:\迅雷下载\archive_with_all`
- `C:\用户\...
`

## 运行方式

双击 `archive_with_all.exe` 即可启动程序。

如果客户需要命令行方式启动，可以说明：

```powershell
C:\archive_with_all\archive_with_all.exe
```

## 备注

当前构建使用无终端窗口模式，运行时不会弹出控制台窗口。

如果客户需要进一步说明或安装帮助，请联系开发者提供详细文档。
