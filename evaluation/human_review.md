# 逐题引用核对记录

本记录是实现过程中对夹具和实际输出的逐条静态核对，不代表独立人工评审。评测脚本会另外校验引用文本确实出现在其来源文件页内；这个检查不等于语义正确率。

| 问题 | 对照夹具后的判断 | 限制 |
|---|---|---|
| 文件题名如何填写 | 两种输出均引用 rules 第1页“照录文件标题，不得自行概括”，直接支持填写规则。 | 另带跨页条款，相关但超出本题必要范围。 |
| 落款单位如何填写 | 引用 rules 第2页“按原文署名的发文单位…不得用收文单位代替”，支持责任者填写。 | “落款单位→责任者”来自显式词表，需要业务人员确认适用范围。 |
| 跨页题名和副题名如何处理 | 引用 rules 第1页核对续行及第2页保留副题名，两个页共同支持。 | Recall@1 无法同时覆盖两页，该题最多为0.5。 |
| 文件日期缺失如何填写 | 引用 rules 第2页“日期缺失时不得猜测”及 ocr_errors 第1页“缺失时不得推测”。 | 后者为人工错字夹具；不自动将日其原文修改成日期，检索中做别名匹配。 |
| 档案密级如何确定 | 两种模式均无答案引用，显示证据不足。 | 即使检索返回含“档案”的片段，也不把它当作密级依据。 |
| 题名是否使用买卖双方名称 | 合同范围资料未进入文书问答，引用的是文书照录规则。 | 没有可直接支持“是否”判断的明确跨类型条款；系统仅展示规则原文并说明未写明情况证据不足，不自动给出是/否。不能把这题计作完整问答成功。 |
| 导出如何操作 | manual 第1页“选择批次后点击导出，Excel按照模板生成对应字段”直接支持。 | 是测试用手册，不代表所有实际界面操作分支。 |

关键词与混合检索的 Recall@1 都为5/6（0.8333），Recall@3 都为1.0；跨页题和 OCR 题各含两个相关页。这是6个有答案问题的宏平均；无答案题不参与 Recall 分母。两种模式14个问答输出的引用来源/页码/逐字文本检查均通过，其中无答案的空引用检查是空集成立，不计为引用质量样本。没有据此计算“答案准确率”。

本地生成器没有自由生成结论；它返回证据摘录，减少无依据扩写。仍可能返回过宽的相关条款、未能回答用户未被规范明确覆盖的情况。实际部署需要扩大独立问题集、业务人员判读与真实扫描件评测。

真实 OCR 另见 ocr_result.json：使用现有 Paddle 本地权重成功识别一张包含三个显式字段的人工生成图片。protobuf 兼容模式及中文路径模型临时复制是本次实测所需条件；未据此报告字符准确率或性能指标。
