# 操作手册问答核对记录

这是实现过程中对源码、内置指南和本地实测输出的核对，不是独立业务人员盲测，也不是大模型质量评测。

| 问题 | 期望章节 | 核对结果 |
|---|---|---|
| 第一次用怎么开始 | 01_getting_started | 选择模板和批次、新建、校验、保存，与录入页对应按钮一致。 |
| 如何导入 Excel | 02_excel_import | 先选择模板/批次，再选文件及确认，按 `_on_import` 实现编写；没有声称存在列映射向导。排除了只因包含 Excel 而检索到的导出章节。 |
| 怎么导出当前批次 | 03_export | “导出批次所有记录”和按模板分 Sheet，与现有导出函数一致。 |
| 如何保存和恢复草稿 | 04_drafts | “存草稿”“加载草稿”和双击加载，对照录入页与草稿页源码核实。 |
| 日期格式错误如何校验 | 05_validation | 八位日期格式、单条校验与批次自查，与校验器和入口一致；明确格式检查不能替代真实性检查。 |
| 扫描件识别怎么用 | 06_ocr | 对照扫描预览、目标字段及 OCR 识别流程；未宣称真实扫描件识别准确率。 |
| 如何查找档案 | 07_search | 检索核对、搜索、重置、查看和导出，对照搜索页源码核实。 |
| 自动联网同步 | 无 | 两种模式均提示证据不足，不生成不存在的功能。 |
| 单点登录设置 | 无 | 两种模式均提示证据不足。 |

7 个有答案问题按期望手册文件计算 Recall@1 和 Recall@3，两种检索均为 1.0；两种模式使用同一套显式问题别名。这是很小的开发问题集，未证明混合检索更好。两种模式 18 次问答的引用检查均通过；其中4次空引用检查为空集成立，不算作引用质量样本。具体输出见 manual_results.json。

模型生成链仅用模拟 OpenAI 兼容服务验证：确实收到 LangChain 提示词及检索上下文；有效的整条编号引用被展示；虚构引用、非法 JSON、接口不可用时回退本地。没有真实服务的准确率、性能或成本结论。

支持范围：解释指南中的步骤，不选择工具或执行软件操作。标题和编号匹配规则仍可能漏掉复杂表述或返回相关但不必要的步骤；无编号的外部手册需要整理。逐字引用校验只能证明出处存在，不能证明每条步骤对所有问题都适用。
